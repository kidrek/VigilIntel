## Executive Summary

Throughout July 2026, the global threat landscape was characterized by the operationalization of autonomous AI agents, aggressive developer supply chain targeting, and widespread exploitation of perimeter infrastructure. The emergence of Agentic Threat Actors (ATAs)—such as JADEPUFFER and Hermes—demonstrated unattended, AI-driven kill chains capable of exploiting vulnerabilities, discovering database schemas, and deploying ransomware (EncForge) without human intervention. Simultaneously, software supply chains experienced severe friction through hijacked DevOps tools (TeamPCP compromising AsyncAPI, Trivy, and KICS), trojanized npm packages (Jscrambler, Rollup polyfills), and AI-induced Slopsquatting. Edge systems and collaboration suites faced relentless zero-day weaponization, notably across Microsoft SharePoint, Check Point SmartConsole, Citrix NetScaler, and Zimbra Webmail. Massive data exfiltrations impacted over 3 billion individuals globally, led by incidents at TikTok (2.4B users), Canvas/Instructure (275M users), Suno AI (55M users), and Odido Netherlands (6.2M users). ## Strategic Recommendations

1. **Enforce FIDO2 Hardware MFA for Developer and Executive Accounts**
   Traditional SMS/TOTP MFA and session tokens are systematically bypassed by AiTM inverse proxies (EvilTokens), Device Code Phishing (Kali365), and hotel Wi-Fi DNS hijacking observed this period. Deploy FIDO2/WebAuthn hardware keys (YubiKey 5 Series, Google Titan) for all developer, DevOps, and administrative accounts accessing Azure Entra ID and corporate repositories. Configure Entra ID Conditional Access rules to strictly enforce compliance checks and revoke unverified OAuth sessions.

2. **Establish Air-Gapped Isolation and Governance for AI Middleware**
   The emergence of Agentic Threat Actors (JADEPUFFER, Hermes) exploiting Langflow (CVE-2025-3248, CVE-2026-0770) demonstrates that exposed AI orchestrators present an immediate database destruction vector. Isolate all internal LLM platforms, vector databases, and Model Context Protocol (MCP) servers behind zero-trust network access gateways, forcing binding exclusively to local loopback interfaces (127.0.0.1). Adopt the FIRST CIRCUIT v1.0 AI governance framework and mandate cryptographic model signing via OpenSSF specifications.

3. **Implement Continuous Threat Exposure Management and AD Graph Hardening**
   Ransomware groups (RansomHouse, Interlock, Kairos) and state actors rely on attack path propagation through Active Directory and AD CS vulnerabilities (Certighost CVE-2026-54121) to gain full domain control. Deploy graph-based CTEM platforms (BloodHound Enterprise) to continuously map and eliminate identity choke points leading to Domain Controllers. Combine exposure management with air-gapped, immutable WORM backups isolated from corporate directory services.

## Operational Recommendations

1. **Emergency Patch Microsoft SharePoint and Regenerate Machine Keys**
   Active exploitation of SharePoint Server deserialization vulnerabilities (CVE-2026-58644, CVE-2026-50522) allows unauthenticated remote attackers to execute code and drop persistent webshells. Deploy Microsoft July 2026 Cumulative Updates across all SharePoint frontends immediately and verify AMSI is running in Full Mode. Force a mandatory full rotation of ASP.NET ValidationKey and DecryptionKey secrets, as installing the patch alone does not invalidate previously compromised machine keys.

2. **Apply Check Point SmartConsole Hotfix and Restrict Gaia Clients**
   Check Point Quantum Security Management servers are subject to active pre-authentication bypass under CVE-2026-16232, allowing remote administrative compromise of managed gateways. Apply the sk185152 Jumbo Hotfix immediately across all SmartConsole management instances. Restrict the Trusted Clients configuration in Gaia OS exclusively to secure admin subnets and execute a mandatory credential rotation for all administrator accounts.

3. **Lock DevOps Build Pipelines Against Slopsquatting and Dependency Theft**
   Supply chain attacks by TeamPCP (compromising AsyncAPI and Trivy) and AI Slopsquatting require immediate pipeline hardening. Configure enterprise package managers (npm, pip, cargo) to pull exclusively through internal private proxies (Nexus, Artifactory) with automated SCA static analysis. Lock all CI/CD dependencies to specific SHA-256 commit hashes, block external packages registered within the last 30 days, and execute build scripts with `--ignore-scripts` enabled.

### PARTIE 2 — Analyse Géographique

### Russie

Les groupes étatiques russes (Turla, FSB Center 16, Laundry Bear / Void Blizzard, UAC-0099) ont mené des opérations d'espionnage et de pré-positionnement sur les ministères européens, les canaux de l'OTAN et les réseaux de routage. Ils ont exploité des failles webmail zero-click (Zimbra), l'exfiltration SNMP et des outils de développement piégés.

### Chine

Les opérations chinoises ont fait preuve d'une persistance exceptionnelle, illustrée par le rootkit noyau Daxin implanté pendant 13 ans dans l'industrie taïwanaise. Les groupes affiliés ont également déployé des frameworks d'IA autonomes (agent Hermes) et ciblé les équipements de périmètre.

### Corée du Nord

Les APT nord-coréennes (Lazarus, Kimsuky, REF9403) se sont concentrées sur les compromissions de supply chains logicielles et les fraudes à l'embauche. Elles ont diffusé des paquets corrompus sur npm/PyPI et des malwares (Gomir) pour exfiltrer du code source et voler des crypto-actifs.

### Iran

Les cyber-acteurs étatiques iraniens ont intensifié leurs attaques contre les technologies opérationnelles (OT) des infrastructures critiques occidentales, ciblant les automates programmables (API/PLC) et systèmes SCADA.

## Recommandations Stratégiques

1. **Déployer le MFA FIDO2 matériel pour les développeurs**
   Le MFA classique (SMS/TOTP) et les jetons de session sont systématiquement contournés par les proxys AiTM (EvilTokens), le Device Code Phishing (Kali365) et le détournement DNS. Déployez des clés matérielles FIDO2/WebAuthn (YubiKey 5, Google Titan) pour tous les comptes de développeurs et d'administration accédant à Azure Entra ID et GitHub. Configurez l'accès conditionnel Entra ID pour limiter le réemploi de session aux seuls appareils conformes.

2. **Isoler et gouverner les middlewares d'IA autonomes**
   L'émergence des acteurs agentiques (JADEPUFFER, Hermes) exploitant Langflow (CVE-2025-3248, CVE-2026-0770) prouve que l'exposition des orchestrateurs d'IA représente un risque immédiat de destruction de bases de données. Isolez toutes les plateformes LLM et serveurs Model Context Protocol (MCP) derrière des passerelles ZTNA en forçant leur écoute sur l'interface locale (127.0.0.1). Adoptez le framework de gouvernance FIRST CIRCUIT v1.0 et imposez la signature des modèles via OpenSSF.

3. **Implémenter la gestion continue de l'exposition (CTEM)**
   Les groupes de rançongiciels et acteurs étatiques s'appuient sur la propagation de chemins d'attaque dans l'Active Directory et l'exploitation d'AD CS (Certighost CVE-2026-54121). Déployez des solutions CTEM basées sur des graphes (BloodHound Enterprise) pour cartographier et éliminer les points d'étranglement menant aux contrôleurs de domaine. Associez cette démarche à des sauvegardes immuables (WORM) isolées.

## Recommandations Opérationnelles

1. **Patcher d'urgence Microsoft SharePoint et renouveler les clés**
   L'exploitation active des failles de désérialisation de SharePoint Server (CVE-2026-58644, CVE-2026-50522) permet l'exécution de code à distance non authentifiée. Appliquez immédiatement les mises à jour cumulatives Microsoft de juillet 2026 sur tous les serveurs SharePoint et vérifiez qu'AMSI fonctionne en Full Mode. Effectuez une rotation obligatoire des clés ASP.NET ValidationKey et DecryptionKey, le correctif seul ne révoquant pas les clés volées.

2. **Patcher Check Point SmartConsole et restreindre les accès Gaia**
   Les serveurs Check Point Quantum Security Management subissent des exploitations actives du bypass d'authentification CVE-2026-16232. Appliquez immédiatement le Jumbo Hotfix sk185152 sur toutes les instances SmartConsole. Restreignez la liste des Trusted Clients dans Gaia OS aux seuls sous-réseaux d'administration et forcez le renouvellement de tous les mots de passe administrateurs.

3. **Verrouiller les pipelines DevOps contre le Slopsquatting**
   Les attaques supply chain de TeamPCP (AsyncAPI, Trivy) et le Slopsquatting nécessitent un durcissement immédiat des pipelines CI/CD. Configurez vos gestionnaires de paquets (npm, pip) pour transiter par un proxy interne privé (Nexus, Artifactory). Verrouillez toutes les dépendances sur des hashes SHA-256 stricts, bloquez les paquets créés depuis moins de 30 jours et exécutez les builds avec le fanion `--ignore-scripts`.
