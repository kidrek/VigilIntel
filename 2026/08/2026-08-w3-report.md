## Strategic Recommendations

1. **Mandate FIDO2 Hardware Keys for Identity Resilience**
   Traditional SMS, push, and OTP multi-factor authentication methods are routinely bypassed by AiTM proxies (Mirage2FA) and voice-phishing campaigns (ShinyHunters, ZeroBytes). Deploy FIDO2/WebAuthn hardware tokens (YubiKey 5 Series, Google Titan) for all administrative and cloud access tiers. Enforce Continuous Access Evaluation (CAE) and strictly restrict session token lifetimes within Microsoft Entra ID.

2. **Enforce Strict Governance on SaaS and Public APIs**
   Mass data extraction campaigns by ExfilSquad and 'City-Forum' prove that default configurations in Salesforce Experience Cloud and Microsoft Power Pages leave Dataverse records exposed to unauthenticated anonymous roles. Establish automated configuration compliance auditing (using CSPM/SSPM frameworks) to enforce deny-by-default on anonymous API endpoints and public Dataverse table permissions.

3. **Isolate Enterprise PLM and Virtualization Control Planes**
   Critical flaws in PTC Windchill (CVE-2026-12569) and VMware vCenter (CVE-2026-59310) demonstrate that edge-exposed enterprise software is actively weaponized for IP theft and total infrastructure takeover. Remove all PLM, vCenter, and hypervisor management interfaces from direct Internet exposure immediately, placing them behind dedicated zero-trust network access (ZTNA) gateways with strict network segmentation.

4. **Implement Rigorous Supply Chain Threat Modeling for AI**
   Over 21,000 exposed Model Context Protocol (MCP) servers and actively weaponized AI framework flaws (Ray CVE-2025-62593, MLflow CVE-2026-64849) demonstrate that AI components are prime initial access vectors. Treat all AI agents and LLM tool-calling integrations as privileged non-human identities with namespace-scoped RBAC, strict egress filtering, and mandatory human-in-the-loop validation for production tasks.

## Operational Recommendations

1. **Patch PTC Windchill and Inspect for JSP Webshells**
   Immediately apply PTC vendor patches for CVE-2026-12569 on all Windchill and FlexPLM instances. Scan web roots under '/Windchill/login/' for hexadecimal-named JSP files matching regex pattern '[0-9a-f]{16}\.jsp' and search web server logs for HTTP headers 'X-windchill-req' and 'X-windchill-prm' or generated 'flst.txt' files.

2. **Block macOS Screen Sharing Port 5900 at Perimeter**
   Mitigate active exploitation of CVE-2026-65400 by applying macOS Tahoe 26.6.1 / Sequoia 15.7.9 / Sonoma 14.8.9 patches. Block inbound TCP port 5900 at all firewalls. Execute 'sudo launchctl disable system/com.apple.screensharing' on all unmanaged endpoints and enforce VPN tunneling for remote assistance.

3. **Audit Microsoft Entra ID for Directory Scraping Activities**
   Query Microsoft Graph Activity Logs for abnormal volume spikes on '/users', '/groups', and '/directoryRoles' endpoints indicative of TheHatman directory dump techniques. Audit privileged role assignments, enforce Microsoft Entra PIM, and revoke all active sessions for high-privilege Global Administrator accounts.

4. **Scan Python Environments for ChocoPoC Malicious Packages**
   Audit all developer and researcher Python environments using 'pip list' and file integrity monitoring to detect compromised packages 'frint', 'skytext', 'slogsec', and 'logcrypt.cryptography'. Search for modified '.pth' files in site-packages and block egress traffic to '91.132.163.78:8001' and suspicious Mapbox API endpoints.

### PARTIE 2 — Analyse Géographique

### Russie

Les cyber-opérations liées à la Russie combinent extorsion de masse très lucrative (Cl0p ciblant la propriété intellectuelle industrielle, RansomHouse frappant Nichirei) et opérations d'influence étatiques. ### Chine

Les groupes étatiques chinois poursuivent leurs campagnes d'espionnage et d'accès persistant. Mustang Panda (HoneyMyte) a modernisé son implant CoolClient avec des rootkits kernel Windows signés, tandis que Salt Typhoon maintient des compromissions d'infrastructures de routage télécom à l'échelle mondiale.

### Autre

Les syndicats cybercriminels (ShinyHunters, ZeroBytes, ExfilSquad, TheHatman, Medusa) dominent l'extorsion ciblant les identités cloud, le SaaS et la supply chain. Ils exploitent le vishing, les contournements de MFA, les API mal configurées (Power Pages/Dataverse) et le scraping massif, délaissant le chiffrement au profit de l'extorsion directe.

## Tendances & Signaux Faibles

**Techniques émergentes :**
- Détournement d'infrastructures Microsoft légitimes pour les canaux C2 (relais Teams TURN WebRTC DataChannels, SharePoint Graph API) par TWINLOOT
- Persistance Windows sans privilèges administrateur via création hors-ligne de ruches de profils obligatoires NTUSER.MAN

**Techniques en déclin :**
- Ransomware par chiffrement pur sans exfiltration préalable massive de données
- Phishing basique par courriel avec pièces jointes binaires non chiffrées, bloqué par les passerelles de messagerie modernes
- Hébergement C2 sur domaines statiques au profit de résolveurs dead-drop légitimes (Mapbox, GitHub, Cloudflare Pages, Discord)

**Contexte géopolitique :** Les tensions géopolitiques dans le Sud-Caucase, en Europe de l'Est et au Moyen-Orient continuent de stimuler les cyber-opérations étatiques. ## Recommandations Stratégiques

1. **Imposer des clés matérielles FIDO2 pour l'identité**
   Les mécanismes MFA traditionnels par SMS, push ou OTP sont systématiquement contournés par les proxies AiTM (Mirage2FA) et le vishing (ShinyHunters, ZeroBytes). Déployez des clés matérielles FIDO2/WebAuthn (YubiKey 5, Google Titan) pour tous les accès d'administration et les accès distants cloud. Activez l'évaluation continue des accès (CAE) et réduisez la durée de vie des jetons de session sur Microsoft Entra ID.

2. **Durcir la gouvernance des API et portails SaaS**
   Les exfiltrations massives d'ExfilSquad et de la campagne 'City-Forum' démontrent que les configurations par défaut de Salesforce Experience Cloud et Microsoft Power Pages exposent les tables Dataverse au rôle anonyme. Mettez en place un audit de conformité continu (SSPM/CSPM) pour interdire par défaut les accès anonymes aux API et restreindre les permissions des tables publiques.

3. **Isoler les plans de contrôle PLM et virtualisation**
   Les vulnérabilités critiques de PTC Windchill (CVE-2026-12569) et VMware vCenter (CVE-2026-59310) prouvent que les logiciels d'entreprise exposés sont exploités pour piller la propriété intellectuelle et contrôler l'infrastructure. Supprimez immédiatement l'exposition publique directe des consoles vCenter et serveurs PLM en les isolant derrière des passerelles ZTNA avec segmentation réseau stricte.

4. **Sécuriser les architectures et déploiements d'agents IA**
   L'exposition de plus de 21 000 serveurs MCP et l'exploitation active de frameworks IA (Ray CVE-2025-62593, MLflow CVE-2026-64849) révèlent que l'IA est un vecteur d'intrusion majeur. Traitez les agents IA et intégrations MCP comme des identités non-humaines privilégiées soumises au moindre privilège (RBAC restreint), au filtrage réseau sortant strict et à une validation humaine pour les actions sensibles.

## Recommandations Opérationnelles

1. **Patcher PTC Windchill et chasser les webshells JSP**
   Appliquez d'urgence les correctifs PTC pour CVE-2026-12569 sur toutes les instances Windchill et FlexPLM. 2. **Bloquer le port VNC 5900 et patcher macOS**

3. **Auditer Microsoft Entra ID contre l'énumération Graph**

Auditez les rôles privilégiés, imposez Entra ID PIM et révoquez les sessions actives des comptes administrateurs globaux.
