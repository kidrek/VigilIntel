## Executive Summary

During Week 2 of August 2026 (Aug 8–12), threat intelligence observed a severe convergence of active zero-day exploitation, critical infrastructure disruption, and sophisticated social engineering. Nation-state group Lazarus exploited a zero-day kernel flaw (CVE-2026-68820) via 'Operation Dream Job' to deploy the FudModule rootkit. Simultaneously, the Gunra and Anubis ransomware-as-a-service (RaaS) operations targeted critical infrastructure, municipal 911 dispatch centers (Suisun City, Coweta), and healthcare providers (AnMed Health, DentaQuest with 15M records breached). Meanwhile, social engineering (vishing and AitM phishing) escalated significantly, with group UNC6671 / Falcon targeting corporate Help Desks and cloud environments (Levi Strauss, financial institutions). On the vulnerability management front, Microsoft's August 2026 Patch Tuesday addressed 415 CVEs, while zero-days in Metabase, Arista VeloCloud Orchestrator, and Cisco Firewalls triggered urgent patching imperatives globally.

## Trends & Weak Signals

**Emerging techniques:**
- IT/OT cross-domain pivoting through private cellular Access Point Names (APNs) without traversing enterprise firewalls
- Help Desk voice phishing (vishing) combined with Adversary-in-the-Middle (AitM) proxies to bypass MFA and capture FIDO2 tokens

**Declining techniques:**
- Reliance on traditional npm installation lifecycle scripts (preinstall/postinstall) now heavily monitored by SCA tools
- Static C2 domain registration without domain fronting or blockchain-based decentralization
- Unencrypted, single-stage ransomware encryptors relying solely on local disk wiping

## Strategic Recommendations

1. **Enforce Hardware FIDO2 MFA for All Help Desk Operations**
   Traditional MFA methods (SMS, push notifications, TOTP) are actively bypassed by UNC6671 and Falcon extortion groups using vishing and Adversary-in-the-Middle (AitM) proxies (e.g., EvilTokens, Evilginx3). Mandate FIDO2/WebAuthn hardware security keys (e.g., YubiKey 5 Series) for all IT Help Desk staff, cloud administrators, and identity provider (Okta, Entra ID) operators. This completely eliminates credential harvesting and session token hijacking risk across corporate M365 and SaaS environments.

2. **Segment Private Cellular APNs and Enforce Zero Trust OT**
   Following the first documented real-world IT/OT pivot via a private cellular APN at a Polish CHP power plant, flat cellular networks can no longer be trusted. Reconfigure private APN routing to strictly block device-to-device communication and enforce mTLS encapsulation with IPSec VPN tunnels between cellular endpoints and OT control zones. This prevents threat actors from pivoting between remote renewable assets (e.g., wind farms) and core industrial control systems.

3. **Remediate Edge Devices and Centralized Orchestrators Immediately**
   Edge management appliances and VPN concentrators are prime targets for initial access, evidenced by active zero-day exploitation in Arista VeloCloud Orchestrator (CVE-2026-16812), Cisco Firewalls (CVE-2026-20349), and Citrix NetScaler (CVE-2025-5777). Apply vendor patches immediately, remove administrative web interfaces from direct Internet exposure, and place management consoles behind zero-trust network access (ZTNA) or strict IP whitelisting. This mitigates unauthenticated remote code execution and session hijacking risks across network perimeters.

4. **Establish Centralized Append-Only WORM Logging Architectures**
   Threat actors deploying ransomware (DeadLock, Gunra, Anubis) systematically wipe local event logs (Windows Event ID 1102/104) and disable security agents to impair forensic analysis. Deploy an immutable, write-once-read-many (WORM) centralized log management solution (e.g., AWS S3 Object Lock, Splunk SmartStore in WORM mode) for all Domain Controllers, edge appliances, and SaaS audit trails. This guarantees audit trail preservation during incident response and prevents anti-forensic log destruction.

## Operational Recommendations

1. **Patch Windows Kernel AFD.sys Zero-Day CVE-2026-68820**
   Lazarus Group is actively exploiting CVE-2026-68820 in Windows AFD.sys to elevate privileges to SYSTEM and deploy the FudModule kernel rootkit. Execute Windows Update or WSUS deployment immediately for the August 2026 Patch Tuesday updates across all endpoints and servers. Hunt for FudModule indicators using YARA rules scanning kernel memory and monitor for unauthorized driver loading via Sysmon Event ID 6.

2. **Audit and Rotate Database Credentials in Metabase**
   Active exploitation of the Metabase unauthenticated SQL injection zero-day (GHSA-vwf4-m7j8-wcjf) allows attackers to read stored credentials for all connected data sources. Update all Metabase instances immediately to versions 1.58.24, 1.59.21, 1.60.17, 1.61.11, 1.62.9, or 1.63.5, and immediately rotate passwords and API keys for every database connected to Metabase. Query web access logs for `POST /api/session/reset_password` returning 400 followed by `GET /api/user/current` returning 200.

3. **Scan Package Lockfiles for Wel1Dropper and ChainDrop**
   Over 780 malicious npm packages (Wel1Dropper) and 400+ packages (ChainDrop worm) were identified using AI slopsquatting to exfiltrate developer credentials and deploy Sliver RAT. Execute `npm audit` and run Software Composition Analysis (SCA) tools (e.g., Socket, Snyk) against all repository lockfiles (`package-lock.json`, `pnpm-lock.yaml`). Block DNS TXT queries to `wel1.ru` subdomains and egress HTTPS traffic to Cloudflare Workers endpoints.

4. **Monitor Network Traffic for Blockchain C2 Function Selectors**
   Botnet loaders like Aeternum and DeadLock ransomware utilize public Polygon RPC endpoints for decentralized C2 communications. Configure NIDS/SIEM rules to inspect HTTP POST payloads to public RPC nodes (e.g., `polygon-bor-rpc.publicnode.com`) for the function selector `0xb68d1809` (`getDomain`) and smart contract call `0x933a9ce8`. Block egress traffic to identified C2 contract addresses and isolate endpoints making high-frequency RPC calls.

## Résumé Exécutif

Au cours de la deuxième semaine d'août 2026 (8–12 août), la veille cyber a enregistré une convergence inédite d'exploitations zero-day actives, de perturbations d'infrastructures critiques et d'attaques d'ingénierie sociale sophistiquées. Le groupe étatique Lazarus a exploité une faille kernel zero-day (CVE-2026-68820) dans le cadre de l'opération 'Dream Job' pour déployer le rootkit FudModule. Parallèlement, les groupes de rançongiciel Gunra et Anubis ont ciblé des infrastructures critiques, des centres de secours 911 municipaux (Suisun City, Coweta) et des réseaux de santé (AnMed Health, DentaQuest avec 15M de dossiers compromis). En Pologne, une centrale thermique a subi un pivot IT/OT via un APN cellulaire privé, provoquant l'arrêt d'une turbine à vapeur—premier cas documenté via ce vecteur. L'ingénierie sociale (vishing et phishing AitM) a franchi un palier, le groupe UNC6671 / Falcon compromettant des Help Desks d'entreprise et des environnements cloud (Levi Strauss, institutions financières). Enfin, le Patch Tuesday d'août 2026 de Microsoft a corrigé 415 vulnérabilités, tandis que des zero-days critiques dans Metabase, Arista VeloCloud et Cisco Firewalls ont imposé des remédiations d'urgence à l'échelle mondiale.

## Réglementaire & Juridique

Les autorités de régulation et les instances judiciaires ont renforcé leurs exigences et mesures de sanction au cours de cette période. Aux États-Unis, le NYS DFS a sanctionné financièrement Order Express (250 000 USD) sous le règlement 23 NYCRR Part 500 suite à des carences révélées par un ransomware, tandis que les tribunaux fédéraux ont encadré strictement le traitement judiciaire des données volées dans l'affaire Change Healthcare. En Europe, la justice française a condamné Meta pour destruction de preuves dans une affaire de publicités frauduleuses, et l'OpenSSF a publié un guide de conformité au Cyber Resilience Act (CRA) européen pour les communautés open source. En Asie, la Thaïlande a proposé d'imposer l'AMF après des fuites massives d'identifiants, tandis que la CAC chinoise a ouvert une enquête de sécurité nationale ciblant Palo Alto Networks.

### PARTIE 2 — Analyse Géographique

### Russie

Les cybercriminels et acteurs liés à la Russie ont maintenu une activité soutenue via des rançongiciels (Qilin ciblant le Stade Français et les VPN Check Point ; Gunra ciblant les infrastructures critiques) et des attaques de chaîne d'approvisionnement (campagne npm Wel1Dropper). Sur le plan tactique, des opérateurs ont enchaîné des CVE sur des caméras IoT et routeurs pour créer des pipelines de proxy et de surveillance visuelle en Ukraine.

### Chine

Des acteurs étatiques ou affiliés à la Chine ont ciblé les fournisseurs de services gérés (MSP) et les infrastructures cloud, exploitant notamment les failles de contournement d'authentification N-able N-central (CVE-2026-18577) pour déployer le rançongiciel StormEncryptor et des tunnels Cloudflare.

### Iran

Les groupes étatiques iraniens ont poursuivi leurs ciblages contre les infrastructures critiques et entités gouvernementales, visant des usines de traitement d'eau aux États-Unis (NJ, Alabama) et menant le projet CAV3RN avec des relais C2 Google Apps Script contre Israël.

### Corée du Nord

Le groupe Lazarus a intensifié l'opération 'Dream Job' contre le secteur de la défense en Europe et en Inde, utilisant de fausses offres d'emploi avec 'SecurityPDF' et le backdoor Troy, combinées à une zero-day kernel Windows (CVE-2026-68820 dans AFD.sys) pour déployer le rootkit FudModule.

### Autre

Les groupes cybercriminels et syndicats RaaS (ShinyHunters, UNC6671/Falcon, Anubis, DeadLock, ExfilSquad, Head Mare) ont provoqué des dégâts majeurs via du vishing/phishing AitM contre les Help Desks d'entreprise, des compromissions de supply chain (CEVA Logistics, zero-day Metabase) et des campagnes d'extorsion.

## Tendances & Signaux Faibles

**Techniques émergentes :**
- Pivot inter-domaines IT/OT via des APN cellulaires privés évitant les pare-feu d'entreprise traditionnels
- Vishing ciblant les Help Desks d'entreprise combiné à des proxies Adversary-in-the-Middle (AitM) pour contourner la MFA et intercepter les jetons FIDO2
- Command and Control (C2) adossé aux blockchains publiques (smart contracts Polygon) et à la messagerie routée en oignon Session
- Injection de prompt par paramètre URL (P2P) dans les assistants IA (ex: Atlassian Rovo) provoquant une exfiltration de données cloud en un clic
- Slopsquatting npm généré par IA déclenchant la charge malveillante à l'importation au runtime plutôt qu'aux scripts d'installation

**Techniques en déclin :**
- Recours aux scripts de cycle de vie d'installation npm traditionnels (preinstall/postinstall) désormais surveillés par les outils SCA
- Enregistrement de domaines C2 statiques sans domain fronting ni décentralisation adossée à une blockchain
- Encryptors de rançongiciels mono-étape non chiffrés reposant uniquement sur l'effacement de disque local

**Contexte géopolitique :** Les tensions géopolitiques se sont traduites par une intensification de la reconnaissance et des opérations offensives contre les infrastructures critiques. Des acteurs affiliés à l'Iran ont élargi leurs cibles dans le secteur de l'eau aux États-Unis (New Jersey, Alabama), exploitant des systèmes SCADA/API pour démontrer une capacité de perturbation. Dans le contexte du conflit russo-ukrainien, des opérateurs russophones ont enchaîné des vulnérabilités sur des caméras et routeurs pour établir des pipelines de surveillance et de proxy en Ukraine, tandis qu'une centrale thermique polonaise subissait un pivot IT/OT inédit via un APN cellulaire privé. En Asie de l'Est, le groupe nord-coréen Lazarus a intensifié l'opération 'Dream Job' contre des sous-traitants de la défense en Europe et en Inde, utilisant une zero-day kernel Windows (CVE-2026-68820) pour déployer le rootkit FudModule. Ces actions soulignent la militarisation croissante des équipements réseau d'extrémité, de la supply chain et des infrastructures cellulaires privées par des états-nations.

## Recommandations Stratégiques

1. **Imposer une AMF FIDO2 matérielle pour le Help Desk**
   Les méthodes d'AMF traditionnelles (SMS, notifications push, TOTP) sont activement contournées par les groupes UNC6671 et Falcon via du vishing et des proxies AitM (ex: Evilginx3). Déployez obligatoirement des clés de sécurité matérielles FIDO2/WebAuthn (ex: YubiKey 5) pour l'ensemble du personnel Help Desk IT et des administrateurs Identity Provider (Okta, Entra ID). Cette mesure neutralise le vol d'identifiants et le détournement de jetons de session sur les environnements M365 et SaaS.

2. **Segmenter les APN cellulaires privés et imposer le Zero Trust OT**
   Suite au premier pivot IT/OT documenté via un APN cellulaire privé dans une centrale thermique polonaise, l'étanchéité des réseaux cellulaires ne doit plus être présumée. Reconfigurez le routage des APN privés pour bloquer la communication directe d'équipement à équipement et imposez une encapsulation mTLS avec tunnels IPSec. Cela empêche un attaquant de pivoter depuis des sites distants (ex: fermes éoliennes) vers les systèmes de contrôle industriels centraux.

3. **Corriger immédiatement les équipements Edge et orchestrateurs centraux**
   Les consoles de gestion Edge et concentrateurs VPN sont la cible prioritaire pour l'accès initial, comme l'illustre l'exploitation zero-day d'Arista VeloCloud Orchestrator (CVE-2026-16812), Cisco Firewalls (CVE-2026-20349) et Citrix NetScaler (CVE-2025-5777). Appliquez immédiatement les correctifs éditeurs, supprimez l'exposition Internet directe des interfaces d'administration et isolez-les derrière un accès ZTNA ou un filtrage IP strict. Cela élimine les risques d'exécution de code à distance non authentifiée et de détournement de session.

4. **Mettre en place une journalisation centralisée append-only WORM**
   Les opérateurs de rançongiciels (DeadLock, Gunra, Anubis) effacent systématiquement les journaux locaux (Windows Event ID 1102/104) et désactivent les agents EDR pour entraver l'analyse forensique. Déployez une solution de journalisation centralisée immuable (WORM/AWS S3 Object Lock, Splunk SmartStore mode WORM) pour tous les contrôleurs de domaine, appliances edge et journaux SaaS. Cela garantit la préservation des preuves d'audit lors des investigations et neutralise les techniques d'effacement de traces.

## Recommandations Opérationnelles

1. **Patcher la zero-day kernel Windows AFD.sys CVE-2026-68820**
   Le groupe Lazarus exploite activement la CVE-2026-68820 dans AFD.sys Windows pour élever ses privilèges vers SYSTEM et installer le rootkit kernel FudModule. Déployez immédiatement les mises à jour du Patch Tuesday d'août 2026 via WSUS/MECM sur tous les postes et serveurs. Recherchez la présence du rootkit FudModule en analysant la mémoire noyau via des règles YARA et surveillez le chargement de pilotes non signés via Sysmon Event ID 6.

2. **Auditer et faire tourner les secrets de bases dans Metabase**
   L'exploitation active de la zero-day SQLi non authentifiée sur Metabase (GHSA-vwf4-m7j8-wcjf) permet la lecture des identifiants stockés de toutes les bases connectées. Mettez à jour les instances Metabase vers les versions 1.58.24, 1.59.21, 1.60.17, 1.61.11, 1.62.9 ou 1.63.5, et réinitialisez immédiatement tous les mots de passe et clés API des bases de données rattachées. Recherchez dans les logs web la séquence `POST /api/session/reset_password` (400) suivie de `GET /api/user/current` (200).

3. **Scanner les lockfiles npm pour Wel1Dropper et ChainDrop**
   Plus de 780 paquets npm malveillants (Wel1Dropper) et 400+ paquets (ver ChainDrop) ont été identifiés utilisant le slopsquatting IA pour exfiltrer des identifiants de développeurs et déployer le RAT Sliver. Exécutez `npm audit` et passez des outils SCA (Socket, Snyk) sur tous les lockfiles de dépôts (`package-lock.json`). Bloquez les requêtes DNS TXT vers les sous-domaines de `wel1.ru` et le trafic HTTPS sortant vers les endpoints Cloudflare Workers listés.

4. **Surveiller le trafic réseau pour les sélecteurs C2 Blockchain**
   Les loaders de botnet comme Aeternum et le rançongiciel DeadLock utilisent les endpoints RPC Polygon publics pour leurs communications C2 décentralisées. Configurez des règles NIDS/SIEM pour inspecter le contenu des requêtes HTTP POST vers les nœuds RPC publics (`polygon-bor-rpc.publicnode.com`) à la recherche du sélecteur `0xb68d1809` (`getDomain`) et des appels smart contract `0x933a9ce8`. Bloquez le trafic sortant vers les adresses de contrats C2 et isolez les hôtes effectuant des requêtes RPC à haute fréquence.
