## Strategic Recommendations

1. **Enforce FIDO2 Hardware Keys Across Identity Providers**
   Threat actor UNC6671 (BlackFile/Helix/Falcon) actively bypasses traditional SMS, TOTP, and push MFA through AiTM proxy portals disguised as FIDO2 migration helpdesks. Deploy hardware FIDO2 WebAuthn keys (YubiKey 5 Series, Google Titan) on Okta and Entra ID for all accounts, particularly in Finance and Tech. Configure Conditional Access policies to enforce phishing-resistant MFA and restrict SaaS tenant access strictly to MDM-compliant managed devices.

2. **Implement Automated Open-Source Software Supply Chain Guardrails**
   Recent supply chain campaigns including Wel1Dropper (788 npm slopsquatting packages) and keyv/cacheable maintainer account takeovers demonstrate severe systemic risks in unverified npm dependencies. Deploy dependency security tools like Socket or Snyk into CI/CD pipelines to block packages executing code upon require() and enforce strict lockfile pinning. Establish mandatory two-person code reviews for dependency version updates and rotate maintainer registry tokens regularly.

3. **Audit and Replace Unvetted Edge Routing Equipment**
   VulnCheck identified pre-installed ENDLESSDOORS backdoors (CVE-2026-66747) across 20+ Zbtlink, Wiflyer, and ZBT cellular router models, creating unauthenticated root shells via Alibaba Cloud C2s. Conduct an immediate hardware audit to remove all Zbtlink/OEM edge devices from enterprise networks, remote sites, and fleet deployments. Replace vulnerable devices with enterprise-grade routing equipment subject to rigorous supply chain provenance checks.

## Operational Recommendations

1. **Apply Hotfixes for N-central RMM Servers Immediately**
   Active exploitation of CVE-2026-18577 and CVE-2026-18556 allows unauthenticated authentication bypass and Cloudflare tunnel persistence on N-able N-central RMM servers. Upgrade all N-central instances immediately to Hotfix 2, restrict management interface access to trusted IP ranges via ACLs, and inspect endpoint process trees for unauthorized Cloudflare tunnel binaries (cloudflared).

2. **Force Patch WinRAR to Version 7.13 Across Endpoints**
   Russian threat actor RomCom actively exploits CVE-2025-8088 (Path Traversal) in WinRAR to drop persistence binaries into Windows Startup folders. Deploy enterprise management tools (Intune, SCCM) to force WinRAR updates to version 7.13+ across all endpoints, as WinRAR lacks native auto-update capabilities. Configure EDR rules to detect executable creation within %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup.

3. **Block Wel1Dropper and FirewallFalcon Indicators of Compromise**
   Malicious campaigns Wel1Dropper and FirewallFalcon Manager utilize distinct C2 infrastructure and persistent artifacts on Linux and macOS. Configure perimeter firewalls and DNS resolvers to block domains zbtctl.epplink.net, online-string.com, and Cloudflare Workers hosts oob-worker.cf103-070.workers.dev. Deploy EDR queries to detect macOS LaunchAgents named com.apple.windowserver.helper.plist and Linux processes executing SHC-obfuscated shell scripts.

4. **Execute File Share Audits Using Sift to Identify Credentials**
   Exposed credentials on network shares remain a primary vector for lateral movement. Deploy open-source credential scanners like Sift across all internal SMB and NFS file shares to identify exposed API keys, passwords, and service account tokens. Immediately rotate any credentials discovered on public or broadly accessible network shares and restrict share permissions using Active Directory security groups.

## Tendances & Signaux Faibles

**Techniques émergentes :**
- Empoisonnement de la chaîne d'approvisionnement piloté par IA ('AI slopsquatting' générant dynamiquement des centaines de paquets npm)
- Campagnes de vishing ciblant les téléphones personnels avec prétexte de migration FIDO2 obligatoire
- Portes dérobées matérielles et firmware préinstallées par les fabricants OEM/ODM (ENDLESSDOORS)

- Remplacement silencieux d'exécutables d'applications macOS post-accès initial sans déclencher Gatekeeper/TCC

- Hameçonnage e-mail traditionnel avec pièces jointes exécutables (déplacement vers le vishing couplé à des portails web AiTM)

**Contexte géopolitique :** Les tensions géopolitiques se traduisent par des contrôles d'exportation technologiques et la fragilité des chaînes d'approvisionnement de défense. ## Recommandations Stratégiques

1. **Imposer des clés matérielles FIDO2 sur les fournisseurs d'identité**
   L'acteur UNC6671 (BlackFile/Helix/Falcon) contourne activement le MFA classique (SMS, TOTP, push) via des portails proxy AiTM prétextant une migration FIDO2. Déployez des clés matérielles FIDO2 WebAuthn (YubiKey 5, Google Titan) sur Okta et Entra ID pour tous les comptes. Configurez l'accès conditionnel pour exiger un MFA résistant au hameçonnage et restreindre l'accès SaaS aux seuls appareils gérés par MDM.

2. **Mettre en place des garde-fous automatisés sur les dépendances open-source**
   Les campagnes récentes comme Wel1Dropper (788 paquets npm) et la compromission des mainteneurs de keyv/cacheable démontrent des risques majeurs sur les dépendances non vérifiées. Déployez des outils de sécurité de dépendances (Socket, Snyk) dans les pipelines CI/CD pour bloquer l'exécution de code au require() et imposer le verrouillage des lockfiles. Exigez une revue à deux personnes pour toute mise à jour de dépendance.

3. **Auditer et remplacer les équipements réseau d'accès non vérifiés**
   VulnCheck a identifié la porte dérobée matérielle ENDLESSDOORS (CVE-2026-66747) sur plus de 20 modèles de routeurs 4G/5G Zbtlink/Wiflyer, fournissant des shells root non authentifiés via Alibaba Cloud. Effectuez un inventaire matériel immédiat pour retirer tous les équipements Zbtlink/OEM du réseau d'entreprise, des sites distants et des flottes. Remplacez-les par du matériel soumis à des vérifications strictes de provenance.

## Recommandations Opérationnelles

1. **Appliquer immédiatement les hotfixes sur les serveurs N-central RMM**
   L'exploitation active des failles CVE-2026-18577 et CVE-2026-18556 permet un contournement d'authentification et l'installation de tunnels Cloudflare sur les serveurs N-able N-central. Mettez à jour toutes les instances N-central vers le Hotfix 2, restreignez l'accès d'administration aux IP de confiance et inspectez les processus pour détecter des binaires Cloudflare non autorisés (cloudflared).

2. **Forcer la mise à jour de WinRAR vers la version 7.13**
   L'acteur russe RomCom exploite activement la faille CVE-2025-8088 (Path Traversal) de WinRAR pour déposer des exécutables dans le dossier Démarrage de Windows. Utilisez vos outils de déploiement (Intune, SCCM) pour forcer la mise à jour de WinRAR vers la version 7.13+ sur tous les postes. Configurez des règles EDR pour détecter la création d'exécutables dans %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup.

3. **Bloquer les indicateurs de compromission Wel1Dropper et FirewallFalcon**
   Les campagnes Wel1Dropper et FirewallFalcon Manager utilisent des infrastructures C2 et artefacts bien définis sur Linux et macOS. Bloquez les domaines zbtctl.epplink.net, online-string.com et les hôtes Cloudflare Workers oob-worker.cf103-070.workers.dev au niveau DNS et pare-feu. Déployez des requêtes EDR pour détecter les LaunchAgents macOS nommés com.apple.windowserver.helper.plist et les scripts shell obfusqués par SHC sur Linux.

4. **Auditer les partages de fichiers avec Sift pour éliminer les secrets**
   Les identifiants exposés sur les partages réseau restent un vecteur privilégié de déplacement latéral. Exécutez des outils de détection comme Sift sur tous les partages SMB et NFS pour identifier les clés API, mots de passe et jetons. Tournez immédiatement tous les identifiants découverts sur des partages accessibles et restreignez les permissions via des groupes de sécurité Active Directory.
